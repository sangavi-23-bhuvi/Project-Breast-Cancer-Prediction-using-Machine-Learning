Breast Cancer Prediction using Machine Learning¶

Classifies breast tumors as malignant or benign using the Wisconsin Breast Cancer dataset (built into scikit-learn, so no download is needed).

Steps: Load data → EDA → Train/test split → Train & compare models → Evaluate best model → Save model → Predict

4. Train / Test Split¶

Stratified 80/20 split keeps the class ratio the same in both sets.

In [6]:
X = df.drop(columns="target")
y = df["target"]

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=RANDOM_STATE)

print("Train:", X_train.shape, "| Test:", X_test.shape)

Train: (455, 30) | Test: (114, 30)

5. Build Models¶

Each model sits inside a Pipeline so scaling is learned from training data only (avoids data leakage).

In [7]:
models = {
    "Logistic Regression": Pipeline([("scaler", StandardScaler()),
        ("clf", LogisticRegression(max_iter=1000, random_state=RANDOM_STATE))]),
    "KNN": Pipeline([("scaler", StandardScaler()),
        ("clf", KNeighborsClassifier(n_neighbors=7))]),
    "SVM": Pipeline([("scaler", StandardScaler()),
        ("clf", SVC(kernel="rbf", random_state=RANDOM_STATE))]),
    "Random Forest": Pipeline([
        ("clf", RandomForestClassifier(n_estimators=200, random_state=RANDOM_STATE))]),
}
list(models)

6. Train & Compare Models¶

Uses 5-fold cross-validation on the training set, then scores on the held-out test set.

In [8]:
rows = []
for name, model in models.items():
    cv_acc = cross_val_score(model, X_train, y_train, cv=5, scoring="accuracy").mean()
    model.fit(X_train, y_train)
    pred = model.predict(X_test)
    rows.append({
        "Model": name,
        "CV Accuracy": round(cv_acc, 4),
        "Test Accuracy": round(accuracy_score(y_test, pred), 4),
        "Precision": round(precision_score(y_test, pred), 4),
        "Recall": round(recall_score(y_test, pred), 4),
        "F1": round(f1_score(y_test, pred), 4),
    })

results = pd.DataFrame(rows).sort_values("F1", ascending=False).reset_index(drop=True)

Conclusion¶

  • Four classifiers were compared on the Wisconsin Breast Cancer dataset.
  • Logistic Regression and SVM both reached ~98.25% test accuracy, with Logistic Regression best in cross-validation.
  • High recall matters here, since missing a malignant tumor is the costly error.
